OKSSOLO — ОБНОВЛЁННЫЙ САЙТ

СТРУКТУРА
- public/index.html — главная страница OksSolo
- public/book-ural.html — страница продажи книги
- public/news.html — архив новостей
- public/admin.html — админ-панель новостей
- server.js — Express, SQLite, ЮKassa и Google Sheets
- public/css/brand.css — новая розово-фуксиевая тема

ВАЖНО ПЕРЕД ЗАПУСКОМ
1. Создайте .env на основе .env.example и заполните действующие ключи ЮKassa, Google Sheets и пароль админки. Не публикуйте .env.
2. В каталоге проекта выполните: npm install
3. Для запуска: npm start
4. Админка: https://ваш-домен/admin
5. Архив новостей: https://ваш-домен/news

БАЗА ДАННЫХ
Файл orders.db намеренно не включён в архив: при первом запуске сервер создаст новую базу автоматически. Если у вас есть действующая база с заказами и новостями, перед заменой сайта сохраните её резервную копию и перенесите отдельно в каталог проекта. Не удаляйте старую базу на сервере.

ФОТО И КОНТЕНТ
- Главная фотография Оксаны: в public/index.html найдите блок hero-photo-placeholder и замените его содержимое на img с вашим фото.
- Книги: public/images/book.jpg; замените файл обложки, если потребуется.
- Четыре фотографии в мини-галерее сейчас используют oksana1.jpg–oksana4.jpg.
- Команда: в public/index.html найдите team-grid. Для каждого участника замените блок team-avatar на img. Тексты модальных окон редактируются в public/js/home.js в массиве data.
- Партнёры: в public/index.html найдите partners-grid и замените текстовые заглушки на изображения логотипов и реальные ссылки.

ПЛАТЕЖИ
Сохранены серверные маршруты для печатной книги, цифровой и аудиоверсии, открыток и webhook ЮKassa. Перед реальным приёмом оплаты проверьте тестовый платёж каждого типа и доступность всех Google Apps Script URL.
